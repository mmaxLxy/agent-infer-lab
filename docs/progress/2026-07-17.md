## 问题与决策

### 开发环境与 GPU 环境隔离

- 问题：直接对现有 14 GiB GPU 环境运行精确同步，可能删除未声明的 vLLM/CUDA 依赖。
- 决策：创建独立 CPU 开发环境，只用于包构建、pytest、Ruff 和 CI 复现。
- 结果：质量检查不依赖 GPU，现有 GPU 环境未被修改。

### 锁文件范围

- 问题：当前 Python 业务代码尚未使用 PyTorch/vLLM；立即锁定完整 GPU 依赖会显著增加解析复杂度和 CI 风险。
- 决策：本阶段只锁定实际使用的项目和开发依赖。首次加入 GPU 业务代码时，再建立独立 GPU 可选依赖组。
