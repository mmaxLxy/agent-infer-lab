## 问题与决策

### WSL 跨盘迁移中断

- 问题：`wsl --manage Ubuntu --move` 在跨卷迁移时返回 `E_ACCESSDENIED`，形成“VHD 已到 D 盘、注册信息仍指向 C 盘”的部分迁移状态。
- 决策：先验证两份备份和 D 盘 VHD，再注销损坏的发行版注册记录，使用 `wsl --import-in-place` 恢复，并重新设置默认用户。
- 结果：数据、用户目录和 GPU 透传均恢复，Ubuntu 注册路径正确指向 D 盘。

### vLLM CUDA ABI 不匹配

- 问题：直接从 PyPI 安装的 vLLM 0.25.1 核心扩展依赖 `libcudart.so.13`，与已选 PyTorch/CUDA 12.9 栈不一致。
- 决策：不伪造软链接，也不额外维护 CUDA 13 Toolkit；改用官方 Release 的 `vLLM 0.23.0+cu129` 精确 wheel。
- 验证：官方资产大小与本地文件均为 500,028,428 字节，SHA256 完全一致；依赖、CLI、Python 导入和 GPU 实算均通过。

### GitHub 大文件下载过慢

- 问题：pip 下载 500 MB wheel 的实测速度约 75 KB/s，预计耗时接近 100 分钟。
- 决策：终止低速临时下载，使用 Windows 自带 BITS 下载到 D 盘缓存，再从本地 wheel 安装。
- 结果：文件完成下载并通过 SHA256 校验，未安装额外下载工具。
