# 2026-08-15：完成 Naive CUDA KV Cache Append 基线

## 今日目标

建立分页 KV Cache Append 的正确性基线：将输入 Key/Value 按照 `slot_mapping` 写入 GPU 上的分页缓存，并用 PyTorch 参考实现、正常用例、边界用例和回归测试验证结果。

## 完成内容

- 实现 Naive CUDA KV Cache Append Kernel。
- 使用缓存布局 `[num_blocks, block_size, num_kv_heads, head_dim]`。
- 支持 FP16 Key/Value 和 int64 `slot_mapping`。
- 在 C++ 绑定层校验 CUDA 设备、连续内存、形状、类型、设备一致性、slot 边界和 slot 唯一性。
- 增加 PyTorch `index_copy_` 参考实现，作为 CUDA 结果的正确答案。
- 增加 Append 冒烟测试，覆盖跨 Block 写入位置 `[0, 15, 16, 17, 35, 127]`。
- 增加边界测试，覆盖空输入、单 Token、Block 边界，以及 8 类非法输入。
- 保留原有 slot 解析 CUDA 测试，确认新增功能没有破坏旧接口。
