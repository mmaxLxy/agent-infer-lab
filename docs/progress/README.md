# 阶段工作记录

本目录按自然日记录 AgentInferLab 的阶段进展，文件名固定为 `YYYY-MM-DD.md`。

每份记录只包含四类信息：

1. **完成项**：当天已经完成、且经过验证的任务。
2. **验证证据**：版本、命令结果、提交或产物路径。
3. **问题与决策**：遇到的问题、根因和最终选择，保留工程判断依据。
4. **下一步**：尚未完成的最小后续动作，不把计划写成已完成事项。

记录原则：

- 只写可复验的事实，不用“应该可用”代替验收。
- 安装命令执行成功不等于环境完成；必须记录功能验收结果。
- 一个自然日只有一份记录；同日后续阶段完成时追加到当天文件。
- 每次阶段收尾时更新记录，并与对应代码或文档一起提交。
